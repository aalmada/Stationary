# Sources

Use these first-party sources to recheck version-specific APIs, target availability, tooling requirements, and publishing constraints before implementing or updating a .NET MAUI app.

| Topic | Source |
| --- | --- |
| Framework overview and current releases | [.NET MAUI product site](https://dotnet.microsoft.com/apps/maui) |
| Documentation root | [.NET MAUI documentation](https://learn.microsoft.com/dotnet/maui/?view=net-maui-10.0) |
| Application architecture | [Enterprise Application Patterns](https://learn.microsoft.com/dotnet/architecture/maui/) |
| Project and startup | [Single project](https://learn.microsoft.com/dotnet/maui/fundamentals/single-project?view=net-maui-10.0) |
| UI and binding samples | [MAUI samples](https://learn.microsoft.com/samples/browse/?products=dotnet-maui) |
| XAML resources and styles | [Style apps using XAML](https://learn.microsoft.com/dotnet/maui/user-interface/styles/xaml?view=net-maui-10.0) |
| Stateful control appearance | [Visual states](https://learn.microsoft.com/dotnet/maui/user-interface/visual-states?view=net-maui-10.0) |
| CSS support and limitations | [Style apps using CSS](https://learn.microsoft.com/dotnet/maui/user-interface/styles/css?view=net-maui-10.0) |
| Device/platform APIs | [Platform integration](https://learn.microsoft.com/dotnet/maui/platform-integration/?view=net-maui-10.0) |
| Release and test guidance | [Deployment and testing](https://learn.microsoft.com/dotnet/maui/deployment/?view=net-maui-10.0) |
| Reference implementation | [eShop](https://github.com/dotnet/eShop) |

- Prefer pages matching the app's target .NET MAUI version.
- Verify preview features and platform requirements in the current source instead of extrapolating from older MAUI or Xamarin.Forms guidance.
- Treat community packages as separate dependencies: check their current documentation, support status, trimming behavior, and target-platform compatibility.
