Privacy

The app

Stationary connects to fitness machines and heart-rate sensors over Bluetooth. It uses their measurements to show ride telemetry, guide workouts, and record results. Bluetooth access is controlled by macOS permission settings.

Ride history, recorded measurements, and settings are stored locally using macOS application storage and preferences. The app has no account system, advertising, or developer-operated ride-upload service. No analytics SDK is intentionally integrated. Third-party dependency behavior is part of release validation; this page is not a claim of an independent privacy audit.

CSV export creates a copy at the destination you choose. That destination may be managed by a cloud file provider; its own privacy and synchronization policies then apply. The export is not uploaded to a Stationary server.

Retention and removal

Local rides and settings remain until removed from application storage. Deleting the app itself may leave them behind. Back up important data, quit the app, and contact support before manually removing application data; do not delete broad system directories. Exported CSV files and Mac/cloud backups must be managed separately.

This website and downloads

This static website contains no advertising, tracking scripts, or external fonts. GitHub hosts the website, release downloads, source code, and issue tracker. GitHub and your browser/operating system may process requests and connection data under their own policies. See the GitHub privacy statement and Apple's macOS security information.

Checksums verify download bytes, not publisher identity. Website builds are not notarized by Apple.

Support

Use the support page to report issues. GitHub issues are public; do not attach personal fitness data, device identifiers, secrets, or unredacted logs. No private support channel is promised.
